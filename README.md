# hanshs474/kavel

Kavel is a free AI video generator and AI image generator — 4K clips with sound, and images you can run without an account or a card.

This tiny Elm package exposes the official site URLs so apps and docs can link to Kavel without hard-coding strings.

## Example

```elm
import Kavel

home : String
home =
    Kavel.homepage
-- "https://www.kavel.ai"

plans : String
plans =
    Kavel.pricing
-- "https://www.kavel.ai/pricing"
```
